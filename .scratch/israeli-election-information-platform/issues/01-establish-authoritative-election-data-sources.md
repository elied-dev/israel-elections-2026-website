# Establish authoritative election data sources

Type: research
Status: resolved
Blocked by: none

## Question

Which official primary sources can provide the 2026 Knesset election's registered electoral lists, candidate order, ballot status, party and list identifiers, official platforms, and publication schedule? For each source, what formats, update cadence, stable identifiers, access method, and reuse terms are documented?

## Answer

Use the Central Elections Committee's [Lists of Candidates guide](https://www.gov.il/en/pages/candidates-lists-26) as the authority for ballot facts and its [2026 election hub](https://www.gov.il/en/pages/knesset-elections-2026) for dates and notices. Use political actors' own dated publications only for attributed platform statements. No documented 2026 candidate API, stable person identifier, update SLA, or reusable photo source was established, so import reviewed snapshots with product-owned IDs rather than depending on undocumented scraping.

Detailed source matrix and import guidance: [`docs/research/authoritative-election-data-sources.md`](../../../docs/research/authoritative-election-data-sources.md).
