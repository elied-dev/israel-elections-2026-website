# Define the content and evidence model

Type: grilling
Status: open
Blocked by: 01

## Question

What canonical entities and relationships must the specification define for Election Editions, Electoral Lists, Political Actors, candidacies, Policy Positions, Source Proposals, Source Records, tags, quotations, translations, and time-bounded claims? Resolve identity changes, list membership changes, conflicting positions, and multiple sources for the same event without choosing a database technology.
