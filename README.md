# Israeli Elections 2026

A public planning repository for a transparent, multilingual guide to Israel's 2026 Knesset election and its sourced public record.

## Status

The product is being specified through a [Wayfinder decision map](https://github.com/elied-dev/israel-elections-2026-website/issues/1). GitHub Issues are the canonical home for the map, decision tickets, dependencies, and resolutions.

No product implementation has started.
